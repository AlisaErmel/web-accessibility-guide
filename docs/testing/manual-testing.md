# Manual Testing

**Manual testing** involves interacting with the application without relying on automated tools.

---

## Why use it?

- Identifies real usability issues  
- Complements automated tools

## When to use it?

During the development phase and after deployment for verification.

## How to test

**Keyboard Navigation:**

- Use `Tab` / `Shift + Tab` to navigate through interactive elements  
- Check focus visibility  
- Ensure a logical navigation order  

## What to check

- Navigation flow  
- Button accessibility  
- Form usability  

## Tips & Best Practices 💡

- Test using only the keyboard (without a mouse)  
- Test slowly and carefully  

> **Manual testing is essential for validating real-world accessibility.**
